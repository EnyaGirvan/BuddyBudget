# BuddyBudget
A C# console app for tracking user income and expenses.
Saves entries to transactions.json in the app folder

 ---- Features ----

-Record income and expenses with an amount, catagory and description with the days date
-List and delete entries
-See a monthly income, expense, balance report

---- Code Organisation ----

-Program.cs starts the app and connects the parts
-BudgetApp.cs handles main menu and user interaction
-Transactions.cs defines a transaction and its income/expneses
-TransactionStore.cs loads and saves transactions as .json

---- Learning Note ----

and adapted to help understand how the code works/ help troubleshoot some errors.
