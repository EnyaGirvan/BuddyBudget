# BuddyBudget
A C# console app for tracking user income and expenses.
Saves entries to transactions.json in the app folder

 ---- Features ----

-Record income and expenses with an amount, catagory and description with the days date

-List and delete entries

-See a monthly income, expense, balance report

---- Code Organisation ----

-Program.cs starts the app and connects the parts (completed)

-BudgetApp.cs handles main menu and user interaction (in progress)

-Transactions.cs defines a transaction and its income/expneses (in progress)

-TransactionStore.cs loads and saves transactions as .json (in progress)
